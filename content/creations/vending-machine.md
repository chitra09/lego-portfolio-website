LEGO Ideas Minifigure Vending Machine — a 1,343-piece retro gumball-style prize machine that really works. Drop in a brick-built coin, turn the knob, and a capsule rolls down into the tray. The set comes with 16 minifigures hidden inside the capsules, so you never know which one you'll get.
